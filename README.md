# Ruleta-Grupos

Ruleta para armar los grupos del **TP Final - YoLo v1** · Redes I / Software II · 5to 1ra.

**Abrir la ruleta:** https://prof-nkocussi.github.io/Ruleta-Grupos/

## Uso

1. Cargá la lista de estudiantes (un nombre por línea).
2. Girá con el botón central, Espacio o Enter. Cada dos giros se arma un grupo.
3. Al terminar, copiá los grupos o descargalos como `.txt`.

La lista y el sorteo quedan guardados en el navegador, así que se puede recargar la página sin perder nada.
